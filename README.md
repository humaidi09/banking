# Banking System

A browser-based banking system demo. Open accounts, make deposits and
withdrawals, move money between accounts, and follow your balances and
transaction history — all client-side, with state kept in the browser.

**Live demo:** https://humaidi.me/banking/

## Built with

React 19 · Vite · Tailwind CSS v4 · React Router · Zustand · Framer Motion

## Run locally

```bash
npm install
npm run dev
```

Open the printed local URL (the app is served under `/banking/`). Build for
production with `npm run build`.
